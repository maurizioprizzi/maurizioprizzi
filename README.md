## Engineering principles

- Mathematical assumptions should be explicit and testable.
- Experimental estimates should not be presented as certified measurements.
- Machine-learning systems need production-quality software engineering, not only notebooks.
- Architecture should isolate domain logic from frameworks and hardware dependencies.
- Resource efficiency and reproducibility are engineering requirements.
- Documentation should record both decisions and limitations.
